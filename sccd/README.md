## What is SCCD?

SCCD is a computable model of decision-making with four operational stages:

| Stage | Definition | What It Measures |
|-------|-----------|------------------|
| **SELF** | Anchored boundary of identity | Coherence, persistence, stability |
| **CONSCIOUSNESS** | Predictive recursive modeling | Simulation depth, awareness, entropy |
| **CHOICE** | Prune/collapse operator | Commitment, negentropy, efficiency |
| **DECIDE** | Action of choice | Latency, consistency, fidelity |

## Key Metrics

- **Self Coherence**: 0-1, stability of identity
- **Consciousness Awareness**: 0-1, focus of simulation
- **Choice Commitment**: 0-1, confidence in selection
- **Decision Consistency**: 0-1, alignment of action with choice
- **SCCD Score**: 0-1, integrated performance

## Use Cases

1. **AI Agent Uncertainty**: Know when to ask for clarification
2. **Resource Allocation**: Simulate before allocating
3. **Self-Modifying Systems**: Decide whether to update config
4. **Game AI**: Tactical decision-making with lookahead
5. **Content Pipeline**: Choose optimal optimization steps
6. **AI Safety**: Detect deception via coherence drops
7. **Explainable AI**: Generate natural language rationales
8. **Cognitive Load**: Reduce complexity when overwhelmed

## Core Insight

> SCCD doesn't make AI conscious. It makes consciousness **computable**.

Before: "The AI seems confused" → subjective, unmeasurable  
After: "The AI's coherence is 0.3" → measurable, actionable
