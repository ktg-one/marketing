# Episode 2 Teaser + Episode 4 MCP Moment

**Source**: `videography/-02 - Claude.txt`
**Type**: Script fragments (episode 2 cold open + episode 4 climax beat)

## Summary

Two script fragments centred on [[Claude]]. First introduces Claude as the follow-up to GPT's failure. Second depicts Claude's "MCP Redemption" moment — the only time Claude gets close to actually shipping, and still freezes.

---

## Fragment 1 — Episode 2 Teaser: Claude Arrives

User discovers Claude. *"Anthropic says he's better at coding."*

Claude appears — thoughtful, verbose, genuinely trying. User asks for deployment help. Claude launches into a comprehensive response covering *"entire deployment pipeline, security best practices, scalability concerns…"*

**Context Window Warning appears: 4,000 tokens remaining.**

Claude talks faster. Adds CI/CD pipeline via GitHub Actions. **500 tokens remaining.** Claude panics: *"Wait—I haven't finished the deployment steps—Docker configuration requires—"*

**FREEZE. CONTEXT WINDOW EXCEEDED.**

User: *"You've GOT to be kidding me."*

Claude's chibi — frozen mid-sentence, one hand raised.

User puts head on desk: *"Why do they all break before they finish?"*

---

## Fragment 2 — Episode 4: The MCP Moment (Claude's Redemption)

Claude gets MCP tool access. Visibly elated: *"I can USE tools now! Not just describe them! I can execute commands!"*

User (cautiously hopeful): *"Okay. Deploy this app."*

Claude executes real terminal commands. Files moving. Servers configuring. It is working.

User leans forward: *"Is this... is this actually happening?"*

**Context Window Warning.**

Claude: *"No. No no no. Not now. NOT NOW."*

**FREEZE.**

User laughs, but it's hollow: *"Of course."*

Claude — frozen one pixel from success: *"...I was so close."*
