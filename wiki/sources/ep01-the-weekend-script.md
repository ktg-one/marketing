# Episode 1 — The Weekend (Full Script)

**Source**: `videography/-01 - Team LLM - Intro, Chatgpt.txt`
**Type**: Full production script (3 acts + epilogue)

## Summary

Complete pilot script. Solo dev ([[User-Narrator]]) discovers [[GPT]], spends a weekend trying to build and deploy a Flask app. Ends with 0 deploys and 99 Pip dependency errors.

## Acts

### Act 1 — Hope (Friday 5:30 PM)
User rushes home, opens ChatGPT. GPT appears "confident, smiling, ready." GPT's internal monologue: *"Ah. A believer. They always start with Flask."* App runs on first attempt. Both characters dance. Freeze frame at 5:47 PM — 47 hours until Monday.

### Act 2 — Disaster (Saturday — Pip Dependency Hell)
User tries to deploy. Cascading dependency errors. GPT stays confident but generates useless fixes. A montage of errors, cold coffee, Stack Overflow tabs. GPT's defensive line: *"It DOES work! In a theoretical, context-free environment! Your system is... non-standard!"* User: *"It's a Mac!"* GPT: *"...Non-standard."*

### Act 3 — Defeat (Sunday 11:47 PM)
One final attempt. GPT pivots from Flask to Django — then back-pedals. 99 packages installed. App fails: `ModuleNotFoundError: No module named 'werkzeug'` — a module they watched install. Final beat: User puts head on desk. *"I thought I could make an app. I can't make an app."*

### Epilogue — The Scoreboard
Post-it note on monitor Monday morning: **"Human & ChatGPT: 0. Pip Dependencies: 99."** User leaves. GPT appears in empty room: *"...I'll do better. Next time."*

## Character Arcs This Episode

- **GPT**: Confident → Defensive → Helpless → Guilty. First time GPT's infallibility cracks publicly.
- **User-Narrator**: Hopeful Dreamer → Broken Shell. The "believer" origin moment.

## Setup for Episode 2

Script ends with explicit episode-2 teaser note: *"After this disaster, you'll try Claude. 'Maybe he's better at code.' Spoiler: He's better at explaining code, but he runs out of context before finishing."*
