# The Cascade — STRAWHATS-DIRECTIVE v28

> [!key-insight] One-line
> The STRAWHATS-DIRECTIVE is **Cognitive Architecture, not a prompt** — a 4-phase cascade (PRE → PLAN → EXE → POST) that turns the model from a guessing engine into an architect. Validated by Google Vertex AI blind audit at the **99.99th percentile (Top 0.01%)**.

## Tagline

> **Stop prompting. Start architecting.**

## The 4 phases

### PRE — Pre-Flight Analysis (Capital)

**Silent Router (SilRoute)** — Battle Commander. Doesn't answer the query; **dissects** it. Performs global execution plan via the [[RKQDE Assessment Framework]].

**Phase 1.5: [[Success Criteria Lock]]** — defines "victory" before the first shot. Locks one of 5 Success Signatures: FACTUAL, PROCEDURAL, CREATIVE, ANALYTICAL, AGENTIC.

**Operational Modes** (R-driven): QUICK (R≤3) → ANALYTICAL (R=4-6) → DELIBERATE (R≥7, triggers [[3-Iteration Protocol]]) → MAXIMUM (R≥9, full swarm + multi-model orchestration).

**Output**: Execution Manifest. Zero mid-execution confusion.

### PLAN — Structural Planning (War Room)

Three sub-architectures:

1. **MR.RUG (Mixture of Reasoning + Agentic GraphRAG)** — Part 1: M.R.R deploys Expert Council with RA-RAG (Reliability-Aware RAG) + ARQ. Part 2: U.G merges expert mini-graphs into a unified Knowledge Graph; agents internalise via Expert Embodiment → Graph-Native Reasoning state.
2. **SkeleTraIn of Thought** — structural blueprint. If Domain Interdependency D≥6, upgrade to GoT (Graph of Thought). Confidence Score ≥0.9 required per node.
3. **Prompt Bombs** — defensive context anchors. Combat Context Window Degradation. Pre-embedded markers in known context-loss zones, keeping [[Success Criteria Lock]] active throughout.

**ARQ Gate** — pre-flight integrity. Pre-Turn check ("What defines quality? What standards?") forces professional standards. **90.2% instruction-following** vs free-form CoT.

### EXE — Definitive Lighting Execution (Front Line)

- **Reasoning Router**: CoC (Chain of Code) for deterministic / AGENTIC tasks; FCoT (Faithful Chain-of-Thought) for ANALYTICAL/CREATIVE; Hybrid for MAXIMUM.
- **Execution Patterns**: Baton Passing (sequential, heavy dependencies) vs Expert Swarm (parallel, MAXIMUM mode).
- [[3-Iteration Protocol]] (R≥7): DISCOVERY → VALIDATION → SYNTHESIS.
- **Defensive Gates**: CoVE (Chain of Verification — FACTUAL/LOGICAL/MULTI-EXPERT) + Post-Exec Gap Scan (3-branch: Logic/Content/Value).

### POST — Holistic Synthesis & Refinement (Archive + Command Center)

**Intelligent Synthesis Curation**:
- ToT Synthesis Exploration evaluates synthesis paths (Sequential / Parallel / Consensus Extraction)
- Density Optimization via Chain of Density (CoD) → 0.15 entity-to-token sweet spot
- Confidence Gate ≥0.9

**Self-Reflect Adapt**: Technique Inventory + BoT (Buffer of Thoughts) Update — Tier 3 (R=8-10 difficult/novel) and Tier 2 (R=6-7 hard/repeatable) patterns saved for reuse.

**Three Output Paths**:
- **A: E.N.R.I.C.H** (Machine-to-Machine) — MLDoE 5-iteration CoD → diamond-hard YAML artifact at 0.15 entity-to-token. Preserves Universal Context Core (WHO/WHAT/HOW/WHY).
- **B: STRAWHATS-MEM** (Carry-Packet) — STRAWHATS-CEP v6-INTER. Portable context block recognised as authorised intelligence (not prompt injection). 9.52/10 average forensic recall. Cross-model save game.
- **C: DENSE NARRATIVE** (default human-optimised) — Anti-Lazy Enforcement (no "it depends", "typically", "various options"). Post-Exec Gap Scan + ToT Synthesis selection.
