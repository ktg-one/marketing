Flagged for review.

> [!contradiction] Claude — green owl vs orange/white
> This document defines Claude as "Green owl, glasses." The [[sources/team-llm-production-bible]] and [[Claude]] cast page define Claude's palette as "orange, warm white." The cast page was built from the production bible. **Green owl** appears to be an error in this document OR a costume variant. The [[CLAUDE.md]] cast page says "Orange and white chibi." Flagged for review.

## Core Loop Gag (Section 2)

Used in every short:

```
1. Sterile Prompt Zone (masks on)
2. Siren fires
3. Masks off
4. Neon city reveal
5. User cutaway (boring office)
6. Back to chaos
7. Punchline line
```
