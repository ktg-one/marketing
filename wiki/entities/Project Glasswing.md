# Project Glasswing

[[Anthropic]] security initiative announced **one week after** the [[Source Map Leak Pattern|March 31 leak]]. Unveiled alongside [[Claude Mythos]] Preview.

## Capabilities cited

[[Claude Mythos]] had already found thousands of zero-day vulnerabilities in every major operating system and web browser. Some bugs decades old.

> [!key-insight] FreeBSD RCE
> One bug — a 17-year-old remote code execution flaw in [[FreeBSD]] — found and exploited fully autonomously.

## Partners

AWS, Apple, Google, Microsoft, NVIDIA, CrowdStrike, the Linux Foundation. **12 launch partners, 40 additional organisations.**

## Funding

**$100M in usage credits committed.**
