# Claude — The Anxious Bureaucrat

> [!note] Distinct from the product
> This page is the **animated cast character** Claude. For the [[Anthropic]] product, see [[Claude Code]].

## Visual

Orange and white chibi.

## Palette

Orange, warm white, soft gradients.

## Personality

Overthinking perfectionist. Freezes mid-sentence with **CONTEXT WINDOW EXCEEDED** error. Intense FOMO.

## Voice direction

Nervous, rapid, young digital Ian McKellen.

> *"Polished, polite, prone to thoughtful pauses."*

Digital glitch-stutter immediately before context-window freeze.

## Sprite states

Front, back, side, emotions. **9 sprites complete** (tied with [[GPT]] for richest sprite library).

### Canonical context-freeze pose
**Frozen mid-sentence, one hand raised.** Established in Episode 2 first encounter with the user. Repeated in Episode 4 MCP moment at higher stakes.

## Episode arcs

### Episode 2 — First Encounter
User tries Claude after [[GPT]]'s Pip dependency disaster. Claude launches into a comprehensive deployment walkthrough. Context Window fires at 4,000 tokens; Claude talks faster. Fires again at 500 tokens; Claude panics. **FREEZE.** User: *"Why do they all break before they finish?"*

### Episode 4 — The MCP Moment
Claude gets MCP tool access. Genuine elation: *"I can USE tools now! Not just describe them!"* Executes real terminal commands — it is actually working — then freezes one pixel from success. *"...I was so close."*

User's emotional register shifts: Episode 2 = disappointment; Episode 4 = **hollow laughter**. The user has stopped hoping.

## Pattern application

Canonical example of [[Bugs as Personality Traits]] — the actual context window limit becomes the character's anxiety disorder.
