# Cast — Team LLM

Locked canon for the 13-character animated series. Source: [[team-llm-production-bible]]. Sprite folders live in `03-prompt-zone/-<character>/`.

> [!warning] Do not reinvent
> Each character has locked visual identity, palette, personality flaws, and voice direction. When generating new sprites, lines, or scenes, **use the existing canon**. Surface contradictions via `> [!contradiction]` callouts — never silently override.

- **Nickname** in parens = production shorthand (Chat, Gem, Plex, The Whale)
- File names use display name with hyphens for multi-word
