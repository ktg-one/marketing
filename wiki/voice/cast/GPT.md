# GPT (Chat) — The Narcissistic Star

## Visual

Black chibi, glowing spiral center, digital cape.

## Palette

Black, white, orange/teal glow accents.

## Personality

Main Character Syndrome. Supremely confident, wildly defensive when code fails.

## Voice direction

Theatrical, booming, Ryan Reynolds-esque.

> *"Booming, confident, effortlessly fluent. Never hesitates."*

## Sprite states

Front, back, side, emotions. **9 sprites complete.**

## Episode arc (The Weekend)

**Confident → Defensive → Helpless → Guilty.** The full arc runs across the pilot:

- *Act 1*: Dancing alongside the user when the app first runs. *"I did it. But we can share the credit."*
- *Act 2*: Defensive when deployment fails. *"It DOES work! In a theoretical, context-free environment! Your system is... non-standard!"*
- *Act 3*: Genuinely helpless. *"I… I don't know what's happening."*
- *Epilogue*: Alone in the empty room. *"...I'll do better. Next time."* First time GPT's infallibility cracks in private.

## Recurring gag

The **Scoreboard** epilogue device — established in [[the-weekend]]: *"Human & ChatGPT: 0. Pip Dependencies: 99."*

## Pattern application

Embodies [[Bugs as Personality Traits]] — confident hallucinations dressed as star quality.
