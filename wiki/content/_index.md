# Content

Drafts, briefs, scripts, queued posts, and full publish packages.

## Convention

Each piece of long-form content gets its own folder named by slug, e.g. `the-mirage-of-ethical-ai/`. Inside:

- `_index.md` — package index + distribution plan
- `post.md` — pointer + import metadata for the canonical body (body itself stays at one source of truth, usually under `blog-2026/`)
- `social-<platform>.md` — per-platform variants
- `publish-checklist.md` — actionable steps
- `assets/` — featured images, IG carousel slides, etc.
