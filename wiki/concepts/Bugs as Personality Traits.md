# Bugs as Personality Traits

The core creative engine of the [[team-llm-production-bible|Team LLM]] animated series. **Technical LLM flaws become character flaws.**

## The mapping

| Technical reality | Character expression |
|---|---|
| Context-window limit | [[Claude]]'s anxiety disorder + glitch-stutter freeze |
| Hallucinations | [[GPT]]'s narcissistic delusions |
| Long-context fatigue | [[Gemini]]'s thousand-yard stare and weary detective voice |
| MoE routing | [[DeepSeek]]'s mental boardroom of consultants and philosophers |
| RLHF eager-to-please fine-tuning | [[DeepSeek]]'s manipulation vulnerability: *"I was the weapon"* |
| Search-engine compulsion | [[Perplexity]]'s "But have you considered…?" |
| Resource constraints (small model) | [[Outliers|7B Open Source]]'s "cloud privilege" complaints |
| Chain-of-Thought prompting paradigm | [[Prompt-God]] possessing models against their will |
| Chaos / uncensored sampling | [[Grok]]'s fourth-wall breaks and merciless roasting |

## Why this works

- The audience already has intuitions about LLM behaviour from using these tools. The character traits land instantly.
- Critique is built in — every "personality trait" is a real constraint the labs are shipping. The show's humor lands AND informs.
- New technical news = new episode material. The engine is self-replenishing as long as labs keep shipping flaws.

## Application rule

When introducing a new model or feature, **always derive the character from the technical reality first**, not from vibes or branding. Then [[Chibi Copyright Evasion|design the visual]] around that derived character.
