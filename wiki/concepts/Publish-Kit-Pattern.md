# Publish Kit Pattern

An 8-file content distribution bundle generated per post by the [[ktg-one]] pipeline. The primary output of the bash template pipeline (`pipeline/run.sh`). Represents the pragmatic resolution of the "auto-post is mostly impossible" constraint.

## The 8 Files

| File | Platform | Format |
|---|---|---|
| `linkedin.txt` | LinkedIn | Professional article (copy-paste) |
| `reddit.txt` | Reddit | Discussion post (copy-paste) |
| `x-thread.txt` | X (Twitter) | 8-post thread (post one by one) |
| `meta.txt` | Meta (Facebook/IG) | Casual/emoji post (copy-paste) |
| `medium.md` | Medium | Full article (import story) |
| `buffer.csv` | Buffer | Bulk upload for LinkedIn/X/Meta queue |
| `review-checklist.md` | Internal | Quality gate — human works through before publishing |
| `all-image-prompts.md` | Google AI Studio | 4 image specs for manual generation |

## Location Pattern

```
pipeline/publish-kit/<post-slug>/
├── README.md               — quick start guide
├── linkedin.txt
├── reddit.txt
├── x-thread.txt
├── meta.txt
├── medium.md
├── buffer.csv
├── review-checklist.md
└── all-image-prompts.md
```

Example: `pipeline/publish-kit/ai-agents-replace-engineers-2028/`

## Why Copy-Paste Instead of Auto-Post

Auto-posting is blocked on most platforms:
- **X**: API costs $5K/month — effectively unavailable
- **Meta**: Requires business account verification — blocked
- **Medium**: API is read-only for most users
- **LinkedIn/Reddit**: Possible via [[Composio]] but requires wiring

The Publish Kit pattern makes the unavoidable manual step efficient: all variants are generated at once, ready to paste, taking ~10 minutes to distribute across 5 platforms.

## Generation Method

Generated by `pipeline/run.sh` (bash templates — 2 seconds, $0 cost). An AI-enhanced version via `pipeline/ktg_pipeline/` (Python, ~2,000 lines) exists but is untested. See [[project-state]] for status.

## Lesson Learned

> "11-agent swarm was overengineering. Bash template works, is fast, is reliable. Publish kit pattern works — humans review, humans publish, AI generates." — PROJECT_STATE.md

## [[Review-Gate]] Integration

The `review-checklist.md` inside the kit is the [[Review-Gate]] artefact. A human works through the checklist and then types `YES` in the pipeline to trigger [[Composio]] for the auto-postable channels (LinkedIn, Reddit).
