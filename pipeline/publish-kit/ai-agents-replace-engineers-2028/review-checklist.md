# Review Checklist — Publish or Reject

## Content Quality

- [ ] Title is compelling and accurate
- [ ] Opening hook grabs attention in first 2 lines
- [ ] Key statistic (40%) is sourced or marked as estimate
- [ ] Three skills are clear and actionable
- [ ] Call to action is present and relevant
- [ ] No typos or grammar errors

## Platform Fit

- [ ] LinkedIn: Professional tone, no emoji overload
- [ ] Reddit: Conversational, question at end
- [ ] X: Thread flows logically, each post stands alone
- [ ] Meta: Emoji-heavy, casual, image required
- [ ] Medium: Full article, canonical link included

## Images

- [ ] hero.png (1200x675) — blog header
- [ ] hero-linkedin.png (1200x628) — professional
- [ ] hero-x.png (1200x600) — bold/contrast
- [ ] hero-square.png (1080x1080) — social friendly

## SEO

- [ ] Title tag under 60 chars
- [ ] Meta description under 160 chars
- [ ] Canonical URL set
- [ ] Schema.org JSON-LD included
- [ ] Keywords targeted

## Legal/Ethical

- [ ] No false claims (40% stat is marked as "top startups report")
- [ ] No defamation
- [ ] Original content (not plagiarized)
- [ ] Disclosure if sponsored (not applicable)
