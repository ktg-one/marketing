## Files Included

- `linkedin.txt` — Professional article format
- `reddit.txt` — Conversational with question hook
- `x-thread.txt` — Numbered thread, copy each post
- `meta.txt` — Emoji-heavy, casual tone
- `medium.md` — Full article with canonical link
- `buffer.csv` — Bulk upload for Buffer queue
- `images/` — 4 image specs (generate separately)

## Publishing Order

1. **Vercel** — Deploy blog post first (get canonical URL)
2. **Medium** — Import story, add canonical link
3. **LinkedIn** — Post article with image
4. **Reddit** — Post to r/artificial or r/programming
5. **X** — Post thread (spacing: 2-3 min between posts)
6. **Meta** — Post with image

## Buffer Upload

1. Go to buffer.com
2. Click "Create Post"
3. Select channels (X, Meta, LinkedIn)
4. Copy content from respective `.txt` files
5. Upload matching image
6. Schedule or add to queue
