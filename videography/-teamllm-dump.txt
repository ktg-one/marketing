I. The Self-Attention Mechanism
For any given input sequence of length L the self-attention mechanism computes an output
representation for each token by considering its relationship to every other token in the
sequence. This relationship is calculated via three learned linear projections of the input token's
embedding: the Query Key and Value (V) vectors.
The attention score between two tokens, i and j, is proportional to the dot product of their
respective Qi and K, vectors. This score determines how much token i "attends" to token j. The
final output for token i is a weighted sum of all the Value (V) vectors. with the attention scores
being the weights.
