# Blog: Content Engine for Rankings & AI Citations

Full-lifecycle blog management: strategy, briefs, outlines, writing, analysis, optimization, schema generation, repurposing, and editorial planning. Dual-optimized for Google and AI citation platforms (ChatGPT, Perplexity, AI Overviews).

## Commands
- `/blog write <topic>` - Write new article from scratch
- `/blog rewrite <file>` - Rewrite/optimize existing post
- `/blog analyze <file-or-url>` - 5-category 0-100 quality score
- `/blog brief <topic>` - Detailed content brief
- `/blog calendar [monthly|quarterly]` - Editorial calendar
- `/blog strategy <niche>` - Blog strategy and topic ideation
- `/blog outline <topic>` - SERP-informed content outline
- `/blog seo-check <file>` - Post-writing SEO validation
- `/blog schema <file>` - JSON-LD schema markup generation
- `/blog repurpose <file>` - Cross-platform content repurposing
- `/blog geo <file>` - AI citation readiness audit
- `/blog audit [directory]` - Full-site blog health assessment
- `/blog cannibalization [dir]` - Keyword overlap detection
- `/blog factcheck <file>` - Verify statistics against sources
- `/blog image [generate|edit|setup]` - AI image generation
- `/blog persona [create|list|use|show]` - Writing persona management
- `/blog taxonomy [suggest|sync|audit]` - CMS taxonomy management
- `/blog notebooklm <question>` - Source-grounded research
- `/blog audio [generate|voices|setup]` - Audio narration
- `/blog google [command]` - Google API data (PSI, CrUX, GSC, GA4)
- `/blog update <file>` - Update with fresh stats

## 6 Pillars
1. Answer-First Formatting - Every H2 opens with 40-60 word stat-rich paragraph
2. Real Sourced Data - Tier 1-3 sources only, inline attribution
3. Visual Media - Images + AI generation + SVG charts
4. FAQ Schema - Structured FAQ with 40-60 word answers
5. Content Structure - 50-150 word chunks, question headings
6. Freshness Signals - Updated within 30 days

## Scoring (100 Points)
- Content Quality (30 pts): Depth, readability Flesch 60-70, originality
- SEO Optimization (25 pts): Headings, title, keywords, internal links
- E-E-A-T Signals (15 pts): Author attribution, source citations
- Technical Elements (15 pts): Schema, images, performance, OG meta
- AI Citation Readiness (15 pts): Passage citability, Q&A format

## Quality Gates (Hard Rules)
- Zero tolerance for fabricated statistics
- Never >150 words per paragraph
- Never skip heading levels (H1→H2→H3 only)
- Tier 1-3 sources only
- Alt text required on all images
- Max 1 brand mention per post
- No duplicate chart types
